## Custom syntax highlighting

Fenced code blocks marked `cachet{:text}` use the grammar in
`src/syntax/cachet.tmLanguage.json{:text}`. It recognises lexical syntax; it does not
resolve names or infer types.

```cachet
// A small function declaration.
fn square : (x: Nat) -> Nat {
  x * x
}
```

Inline code such as `fn square : (x: Nat) -> Nat` uses the same grammar and colours.
